==========
Versioning
==========

Kavanah Analytics follows `Semantic Versioning <https://semver.org/>`_:

.. code-block:: text

   MAJOR.MINOR.PATCH[-STAGE]

   Examples:
     1.0.0-beta   — Beta release
     1.0.0        — General availability
     1.1.0        — Minor feature release
     1.0.1        — Patch / bug fix
