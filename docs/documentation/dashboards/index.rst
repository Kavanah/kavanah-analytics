===============
Dashboard Pages
===============

The Dashboard Pages section covers the analytics and reporting features available
to all authenticated users — viewing dashboards, building custom charts, and
interpreting your engagement data.

   :maxdepth: 2
   :hidden:

**In this section:**

:doc:`dashboard-overview`
   Reference: the platform-tab → data-view map and how the Dashboards
   page differs from the Dashboard Builder. For the user walkthrough
   see :doc:`/guide-dashboards/overview`.

:doc:`dashboard-builder`
   Reference: every chart type, aggregation, breakdown option, and
   the dashboard JSON schema. For the step-by-step guide see
   :doc:`/guide-management-console/dashboard-builder`.

:doc:`reach-metrics`
   Concept explainer: paid versus organic reach, which platforms
   contribute to each, and how to interpret reach across client
   spaces.

:doc:`client-space-management`
   Concept explainer: how organisations and teams structure your
   data, how Primary / Partnerships filter modes work, and how
   server-side data isolation is enforced.

:doc:`automated-reporting`
   The Report Scheduler: scheduled imports that save dashboard
   snapshots, and scheduled emails that send dashboards as a summary
   and link, inline tables, or an Excel or PDF attachment.
