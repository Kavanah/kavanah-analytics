======================
Supported Data Sources
======================

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Platform
     - Data Available
   * - Facebook Ads
     - Ad insights: spend, impressions, clicks, reach, conversions by campaign/ad set/ad
   * - Facebook Pages
     - Page-level organic reach, engagement, fan growth
   * - Instagram
     - Organic reach, impressions, engagement by post and story
   * - Google Ads
     - Campaign performance: spend, clicks, impressions, conversions
   * - Google Analytics 4
     - Sessions, users, engagement metrics, traffic sources
   * - YouTube
     - Views, watch time, subscribers, video-level performance
   * - Echo / Chatwoot
     - Conversation counts, response times, resolution rates by team.
       Echo and Chatwoot are configured separately but share the same
       conversation-data shape, so you'll see two data views in the
       Dashboard Builder: *Echo Conversations* and *Chatwoot
       Conversations*. Chatwoot has an additional *Chatwoot Insights*
       view for daily aggregate metrics.
   * - Disciple Tools
     - Contact pipeline metrics
